# DailyFlow 启动性能基线（2026-09-09）

## 测量范围

本轮把应用初始化拆为数据库、设置、扩展、长期目标和专注恢复五个阶段。运行时使用 `performance.now()` 记录实际耗时，结果显示在“设置 → 关于”，用于定位不同设备和数据量下的启动退化。

## 当前构建基线

- 主应用最大 JavaScript 分块：247.57 KB（压缩前），生产构建实测。
- 构建预算：任一 JavaScript 分块不超过 300 KB（压缩前）。
- 构建警告预算：0 条重复静态/动态导入警告。

本轮生产构建满足两项预算：最大分块 247.57 KB，Vite 重复导入警告为 0。

## 启动阶段预算

| 阶段 | 目标耗时 | 说明 |
| --- | ---: | --- |
| 本机数据库 | 500 ms | 打开 SQLite、迁移与仓库初始化 |
| 用户设置 | 250 ms | 读取设置并应用主题与行为 |
| 扩展系统 | 1000 ms | 加载、初始化并激活已启用扩展 |
| 长期目标 | 500 ms | 读取目标树 |
| 专注恢复 | 500 ms | 恢复未结束的专注会话 |

这些预算用于发现回归，不是强制超时。开发机或首次迁移可能暂时超过预算；应结合连续多次结果和数据规模判断。
