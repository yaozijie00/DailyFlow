# DailyFlow 第二阶段：核心体验与可扩展性

## 目标

在第一阶段可靠性修复的基础上，降低首页操作成本，明确任务信息层级，并为后续页面和扩展功能控制首屏体积。

## 本阶段范围

- [x] 核心页面改为按需加载，提供统一加载占位。
- [x] 今日页提供始终可发现的「收集箱」入口与未安排数量。
- [x] 收集箱便签增加「安排到今日」按钮，拖拽只作为快捷方式。
- [x] 任务详情优先展示状态与主操作，规划信息、内容和历史记录分层。
- [x] 今日摘要收敛为待完成、计划进度、已专注三项决策指标。
- [x] 统计页首屏突出三项核心指标，其余指标进入「更多指标」。
- [x] 将侧栏数据库技术状态改为用户可理解的本机保存状态。
- [x] 运行目标测试、完整测试、构建检查，并确认开发服务热更新。

## 后续阶段

- 时间轴拆分为视口、刻度、任务块和交互控制器，统一颜色语义与可读性。
- 设置项迁移到声明式注册表，支持扩展贡献独立设置分组。
- 为常用桌面窗口尺寸建立回归矩阵和关键流程端到端测试。
