# DailyFlow 第四阶段：时间轴与桌面窗口适配

## 目标

拆解时间轴的显示层与交互控制器，提高键盘可达性，并集中管理桌面窗口断点。

## 本阶段范围

- [x] 提取时间轴任务块组件，使用稳定的视图模型和事件接口。
- [x] 任务块支持键盘打开详情，并提供直接移回收集箱的按钮。
- [x] 为运行、完成和取消状态提供文字或符号，不只依赖颜色。
- [x] 提取时间刻度与背景网格组件，缩小主时间轴组件职责。
- [x] 集中管理侧栏和详情面板响应式断点，并覆盖边界测试。
- [x] 调整今日摘要和页头在窄窗口下的换行行为。
- [x] 建立桌面窗口视觉回归矩阵。
- [x] 运行目标测试、完整测试、构建和开发服务验证。
