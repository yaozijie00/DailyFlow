# DailyFlow 第五阶段：启动诊断与扩展权限

## 目标

让启动性能可观测、扩展能力可审计且由宿主限制，并消除已知构建拆包警告。

## 本阶段范围

- [x] 建立启动阶段耗时记录服务与单元测试。
- [x] 在应用启动流程记录数据库、设置、扩展、目标和专注恢复耗时。
- [x] 在“设置 → 关于”展示本次启动诊断。
- [x] 为 Extension Manifest 增加向后兼容的能力声明和未知值校验。
- [x] 按能力限制任务读写、旧数据读取及 UI 贡献。
- [x] 在扩展管理页展示各扩展声明的能力。
- [x] 更新扩展开发文档，说明权限语义与当前安全边界。
- [x] 清理重复动态导入造成的 Vite 构建警告。
- [x] 运行目标测试、完整测试、构建与开发服务验证。
