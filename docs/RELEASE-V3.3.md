# DailyFlow V3.3

发布日期：2026-09-28。Windows x64，本地 SQLite，无账号要求。

## 本次交付

- 移除 Workflow 与课程表的产品入口、实现和专属依赖；保留通用扩展宿主及旧数据备份兼容。
- 长期工作台统一计划与项目，区分准备、进行、暂停和完成；支持下一步行动、本周投入承诺、容量提示、停滞提醒和保存复盘。
- Focus 使用一个持久化会话，Today、时间轴、任务详情、长期行动、搜索和 Mini 共享状态。离开页面继续计时，暂停不累计投入。
- 结束专注可记录备注、下一步并选择完成任务；支持补录、历史修正、重叠提醒。投入自动汇总到任务、项目、计划及复盘。
- 异常退出后恢复需要用户确认；系统休眠或时钟跳变产生的不确定时段不会静默累计。
- 收集箱与长期笔记分开；输入可转换为任务、计划、项目或想法，支持撤销与重做。
- 搜索精确打开任务、长期事项与笔记；未排期任务可编辑原记录，不会自动排期或创建副本。
- 设置保存失败保留输入并报告失败，不再显示虚假的成功提示。
- 统一主题、焦点与反馈，验证 820/900/1100/1440 像素窗口的阅读与滚动。

## 数据兼容

版本统一为 3.3.0，应用标识及正式数据库位置不变。迁移为增量迁移，保留旧任务、专注历史和退役扩展的数据表。

新增专注有效时段、幂等操作和旧任务时长基线；0033 兼容已经运行过早期 0032 的预览数据库。备注修改不改写原始计时精度与来源。旧扩展历史数据继续进入备份流程。

## 验证

- 前端：97 个测试文件、728 项测试通过。
- 原生：26 项测试通过，包含计时恢复、事务、旧数据迁移、时间跳变与备份。
- TypeScript 与 Vite 生产构建通过；项目未配置单独 lint 命令。
- 真实 Tauri/WebView2：长期 → Today → Focus → Mini → 结束 → 实际投入回流；手动补录；重启恢复及离开时段排除。
- 真实桌面搜索：未排期任务读取/编辑、长期事项定位、笔记搜索自动展开与切换分类。
- 五个核心页面 × 四种窗口尺寸 × 深浅两种主题，共 40 组检查；实际滚轮测试通过，未捕获页面异常。

验证在隔离数据库中进行，不使用正式用户数据。

## 发布边界

- 本版不提供任意脚本扩展的运行时安装器；未来扩展通过宿主接口随构建加入。
- 长期计划支持投入承诺与实际投入对照，不将投入时长伪装成成果完成百分比；高级进度预测与自动重新规划未纳入本版。
- Focus 历史当前最多加载 1000 条；未确认的结束备注草稿不保证异常退出后保留，已持久化的计时不受影响。
- 休眠恢复逻辑有自动测试，未覆盖所有硬件的真实休眠唤醒组合。
- 安装包包含 WebView2 离线安装器；尚未在独立干净 Windows 系统完成升级/卸载测试。
