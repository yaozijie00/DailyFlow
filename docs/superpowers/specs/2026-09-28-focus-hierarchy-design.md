# Focus：任务优先的专注工作区

## 审查与定位

当前页面把上下文、计时、备注、切换任务和中断操作排成同权重长列；运行中仍显示重复浮动控制条，遮挡备注。控制按钮图标与文字换行，历史和模式设置先于执行意图，用户没有明确视觉落点。

比较三个方向：纯居中计时容易弱化任务；双栏仪表盘增加干扰；选择主工作区与次级上下文的非对称布局。

## 方法与参考

- brainstorming：先明确当前状态要完成的用户动作，再组织字段。
- frontend-design：用排版、对齐和留白塑造层级，沿用现有字体/主题，不引入远程字体。
- ui-ux-pro-max：可见焦点、表单标签、对比度、窄窗口重排与 reduced-motion。
- Things https://culturedcode.com/things/ ：简洁任务组织，借鉴渐进呈现。
- Sunsama https://help.sunsama.com/docs/usage-guides/focus-bar/ ：任务计时与跨页面轻量控制。
- Session https://stayinsession.com/learn/getting-started-with-session-pomodoro-app ：意图优先、上下文笔记、结束后反思。

不复制这些产品的视觉皮肤或第二套任务系统。

## 页面方案

Idle：主栏推荐一个可开始的任务，下方搜索与其余任务；次栏配置计时模式与目标，无关联专注为次要入口。无任务时解释下一步，允许搜索并创建真实任务。

Running：主栏状态、任务标题、局部刷新的等宽数字、暂停/结束、简短备注；次栏任务归属、已保存投入与预计时长、计划时间。切换与中断为次级操作。

Paused：显式暂停时长与不累计投入的说明；继续为主操作。

History：统一折叠入口，保留补录、修改、删除与再次专注。运行与空闲不会出现不同位置的历史架构。

在专注页隐藏重复浮动条，但保留结束面板、切换确认和其他页面控制条；Mini 不受影响。

1440：约 1040px 内容上限，主栏/次栏约 2:1。1100：压缩栏间距。900 及以下：单列，次级内容向下自然流动。长标题换行、按钮不折字、没有固定内容高度。

## 验收

- 三种状态均有明确主操作；恢复流程仍可访问。
- 计时数据源及每秒渲染范围不变。
- 深浅主题、900/1100/1440 宽度检查与实际滚动；长标题、空列表检查。
- 浮动条仅在 Focus 页面去重，其他页面及 Mini 正常。
- 现有测试、新增状态测试、类型检查与生产构建通过。
