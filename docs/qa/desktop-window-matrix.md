# DailyFlow 桌面窗口回归矩阵

## 自动检查

先在一个终端运行：

```powershell
npm run dev
```

再在另一个终端运行：

```powershell
python scripts/qa_responsive.py
```

2026-09-09 的结构与溢出检查结果：

| 视口 | 侧栏 | 文档横向溢出 | 控制台错误 | 结果 |
| --- | --- | --- | --- | --- |
| 800 × 600 | 自动折叠 | 无 | 无 | 通过 |
| 960 × 720 | 展开 | 无 | 无 | 通过 |
| 1180 × 800 | 展开 | 无 | 无 | 通过 |
| 1440 × 900 | 展开 | 无 | 无 | 通过 |

报告默认写入系统临时目录 `dailyflow-responsive-qa/report.json`。传入 `--screenshots` 可以额外生成截图；在部分 Vite/Tauri 无头环境中，Chromium 可能持续等待字体状态，此时以结构检查为准。

## 人工视觉检查

每个正式版本在浅色、深色和毛玻璃主题下检查以下组合：

- 800 × 600：侧栏为图标栏；页头操作允许换行；今日摘要不产生页面级横向滚动；任务列表与时间轴仍可操作。
- 960 × 720：侧栏展开；详情使用浮层；收集箱展开后不遮挡时间轴主要操作。
- 1180 × 800：详情切换到右侧栏；拖动详情分隔线时，时间轴保留最小宽度。
- 1440 × 900：任务、时间轴、提醒和详情的视觉层级清晰；重叠任务允许横向滚动。
- 键盘路径：Tab 可聚焦任务块；Enter 或空格打开详情；“移回收集箱”按钮可独立聚焦。
- 状态识别：进行中、已完成和已取消均有符号或文字线索，不能只依靠颜色。
