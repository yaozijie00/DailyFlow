# DailyFlow 第三阶段：扩展设置与时间轴界面边界

## 目标

让新增扩展可以注册自己的设置入口，并把时间轴的显示控制与复杂拖拽逻辑分开，降低后续功能增长时的修改范围。

## 本阶段范围

- [x] Extension Contributions 增加设置分组接口，并校验分组 ID。
- [x] Settings 页面使用声明式分组注册表，渲染启用扩展贡献的设置分组。
- [x] 扩展设置组件使用独立错误边界，单个扩展异常不影响设置页。
- [x] 更新扩展开发文档，说明设置分组注册方式。
- [x] 提取时间轴工具栏，明确当前显示范围、缩放比例和主要操作提示。
- [x] 为工具栏和扩展设置贡献增加组件/平台测试。
- [x] 优化 Vite 公共依赖分包，降低单一启动包继续增长的风险。
- [x] 运行目标测试、完整测试、构建与开发服务检查。
